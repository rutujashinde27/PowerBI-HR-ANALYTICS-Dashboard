# HR Analytics Dashboard | Power BI
# Project Overview
The HR Analytics Dashboard is an interactive Power BI project designed to help analyze employee data and understand key workforce trends. It presents HR information through visual reports and KPIs to support data-driven decision-making.

# Objectives
Analyze employee data and workforce trends.
Monitor key HR metrics using interactive visuals.
Explore employee-related patterns to support HR planning.
Present data in a clear and easy-to-understand dashboard.
Tools & Technologies
Microsoft Power BI
Power Query (for data preparation, if used)
DAX (for measures and calculations, if used)
Dashboard Highlights
Interactive HR report pages and visualizations.
KPI cards and charts for summarizing workforce information.
Filters and slicers to explore the data (where available).
Visual presentation of HR metrics and trends.
Project File
Hr_Analytics.pbix — Power BI dashboard file.
How to Open
Download or clone this repository.
Open Hr_Analytics.pbix using Microsoft Power BI Desktop.
Use the report pages, filters, and slicers to explore the dashboard.
